Quick Start

1. Create or select a case top-right.
2. Upload Logs — drag multiple CSV / JSON / XLS files at once.
3. Click stat cards above to drill into users, events, and log types.
4. Use Search with quick-chips or custom filters.
5. Check Detections for triggered BEC rules — expand each card for IR playbook steps.
6. Open Attack Summary for an automatic phased IR view — Initial Access → Persistence → Collection → Exfiltration → Cover-up → Containment.
7. Review IOCs for suspicious source IPs.
8. Run AI Analysis for Claude's attack-chain assessment.
