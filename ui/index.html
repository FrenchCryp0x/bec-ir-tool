Quick Start

1. Create or select a case in the top-right.
2. Go to Upload Logs to ingest CSV / JSON / XLS files.
3. Use Search to query events (e.g. user~admin operation~InboxRule).
4. Check Detections for triggered BEC rules.
5. Run AI Analysis once your API key is configured.
